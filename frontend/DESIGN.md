# DDevOps 设计系统

发布编排平台的界面目标：**先看清状态，再执行操作**。界面保持石墨中性，颜色只服务于“环境 / 结果 / 操作”，其余部分安静。

## 1. 风格

- 浅色为主，克制玻璃拟态：半透明白卡片、细描边、10px 圆角，不使用大面积渐变或光晕。
- 浅色主题的侧栏与顶栏同为浅色，侧栏用深一档中性底（`#e9edef`）+ 描边与内容区分离；深色主题整体翻转。
- 深色主题用低饱和蓝灰，画布明度约 12%，卡片 / 侧栏 / 顶栏逐级提到 18%–19%，抬升层 21%，不追求纯黑。
- 卡片不靠重阴影浮起，层级主要由描边、明度和留白建立；阴影只服务浮层。

## 2. 配色

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | `#f4f6f7` | `#171d22` |
| 卡片 | `rgba(255,255,255,.84)` | `rgba(35,44,51,.86)` |
| 侧栏 / 顶栏 | `#e9edef` / `#fbfcfc` | `#262f36` |
| 描边 | `#dfe4e7` | `rgba(255,255,255,.10)` |
| 正文 / 次级 / 辅助 | `#161c20` / `#48535a` / `#5f6b73` | `#e9eef1` / `#bcc7cd` / `#9aa8b1` |
| 主操作 | `#2c3f4d` | `#e8eef2`（浅底深字，避免荧光按钮） |
| 强调 / 选中条 | `#4b7391` | `#8fb2c6` |
| 成功 / 失败 | `#2c6e4e` / `#a8433a` | `#8ecfa9` / `#ef9a92` |
| 图表柱 | `#7699b2` / 失败 `#c37b72` | `#6f93ad` / 失败 `#d99a91` |

规则：

- 主色只出现在主按钮、焦点环、链接和侧栏选中条，不铺大面积底色。
- 环境与发布状态使用语义色；同一屏内不同时出现三种以上强调色。
- 正文、次级、辅助文字在各自底色上的对比度均 ≥ 4.5:1（脚本实测）。
- 图表只用一个强调色标记“今天”，其余柱体走中性钢蓝；失败段用小面积陶红。

## 3. 字体与字号

系统 UI 字体（SF Pro / PingFang SC / 微软雅黑），数据使用等宽字体与 `tabular-nums`。

| 用途 | 字号 / 行高 |
| --- | --- |
| 页面标题 | 21 / 29，600 |
| 面板标题 | 13.5 / 20，600 |
| 正文、表格 | 12.5–13 / 20 |
| 辅助说明 | 11.5 / 18–20 |
| 表头、标签 | 11 / 16 |
| KPI 数值 | 28 / 32，600 |

不使用全大写英文眉标、字距拉伸、斜体强调或营销式副标题。图标统一 16px / 1.5 描边。

## 4. 间距与栅格

- 4px 基准；页面左右留白 28（移动端 16），卡片内边距 20（紧凑 16），区块间距 16。
- 表格行高：舒适 12px 上下内边距，紧凑 7px；表头 40px。
- 页面最大宽度 1560，12 列栅格：概览 KPI 4 列、主图 8 列 + 侧栏 4 列。
- 侧栏导航行高 36、间隔 2，分组标题距上一组 24、距本组 8。

## 5. 组件规范

- 按钮：高度 32 / 28 / 24（md / sm / xs），圆角 8；主按钮、次按钮、柔和、幽灵、危险五种层级，均含默认 / 悬停 / 按下 / 禁用 / 加载。一屏只保留一个主操作，主操作置于操作区末尾。
- 表格行操作在桌面端以轻量文字按钮直接展示（构建、详情、编辑、删除），主操作靠右、危险操作红色；移动端收进 `…` 菜单，菜单键盘可操作，Escape 关闭并归还焦点。
- 搜索：全局搜索固定在顶栏右侧（`⌘K`）；列表搜索在表格工具栏左侧，与筛选同区，不与“新建”等主操作混排。
- 输入 / 筛选：高度 32–34，圆角 8；下拉箭头 14×14，右侧 10–12px，垂直居中；焦点用 2px outline，不做渐显。
- 表格：表头浅底、11px 中灰；行悬停变色，选中行用主色浅底；批量操作条出现在表头下方，不遮挡数据。
- 徽标：21px 胶囊，浅色底 + 深色文字，不再附加装饰圆点。
- KPI：只保留标签、数值、单位与一句对比说明，不放图标和迷你进度条。
- 抽屉：右侧 480px，头部 15px 标题，底部操作区带分隔线与浅底。
- 空 / 加载 / 错误：骨架保留表格列宽；错误态提供重试；空态给下一步动作。
- 动效：标准模式 150–240ms；增强模式仅在 KPI 卡片启用柔光倾斜，表格、表单、抽屉始终禁用装饰动效；`prefers-reduced-motion` 优先于开关。侧栏折叠与滑块只动 `transform` / `opacity`。

## 6. 令牌入口

- `src/styles/tokens.css`：颜色、字体、圆角、阴影、动效、密度、布局尺寸。
- `src/styles/global.css`：卡片、按钮、输入、表格、徽标、骨架等原语。
- 业务页面只使用 Tailwind 原子类与上述原语，不写零散配色。

## 7. 工具链与审查记录

按提示词 B 的层级执行，冲突时以本规范为准：

- **UI/UX Pro Max**：按“内部发布/运维后台”生成设计系统，建议 Minimalism & Swiss、深色终端配色与 Fira Sans/Code。采纳其风格与信息密度；其中近黑 `#020617` 与高亮绿按钮违反“深色 12%–20%、禁止荧光按钮”，已按本品类改为蓝灰阶与浅底主按钮。
- **unslop**：审计并修复统计卡图标/迷你条、装饰圆点、列表元信息中的间隔点、等宽标签过小、按钮高度与间距不齐；行操作按用户反馈改为桌面端直接展示、移动端收起。方向定为“控制室 / 石墨 + 雾钢蓝 / 短码签名”。
- **Hallmark**：按 Floor 门禁处理：令牌化颜色、`overflow-x: clip`、可见 focus-visible、`prefers-reduced-motion`、去掉状态装饰点与行内点分隔。`sloplint` 最终 0 FAIL；1 项 REFLEX 为 webhook 代码示例使用等宽字体（属代码，waive）；11 项 WARN 是 Vue 模板中的长标签未声明 nowrap，实际已由外层截断。
- **Impeccable**：Operate 模式审查对齐、间距节奏、对比度与状态完整性；`detect` 仅报 1 条 advisory（弹性缓动），因提示词明确要求侧栏滑块的弹性回弹，保留并记录为有意偏离。
- **taste-skill**：按反模板规则去掉营销副标题、装饰动效与图标噪声；其营销页 gate 不适用于 SPA 后台。
- **Modern Web Guidance**：`menu` 指南用于行操作菜单：`role=menu`、`aria-haspopup/expanded`、方向键、Escape 归还焦点、点击外部关闭、固定定位避免表格裁切。
- **react-bits**：仅适用于 React 项目，本项目为 Vue，未引入；KPI 数字递增与悬停反馈用原生 CSS 实现。
- **andrej-karpathy-skills**：改动只围绕设计系统、按钮/菜单与主题；不重构业务逻辑，不新增依赖。
